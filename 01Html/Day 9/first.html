Introduction to array

what is an array?

An array is a foundational, linear data structure that stores a collection of elements (usually the same data type) in contiguous memory locations. It allows for efficient storage and direct, fast access to items using a numerical index, which typically starts at 0 for the first element.

characterstic of array

  • Homogeneous Data: Arrays store elements of the same data type (e.g., all integers or all floats).
  • Contiguous Memory Allocation: Elements are stored in adjacent memory locations, which improves cache performance.
  • Fixed Size: The size of a traditional array is defined at declaration and cannot be changed during runtime, preventing automatic resizing.

types of array

  1. One-Dimensional (1-D) Array: A linear list of elements accessed via a single index
    • example: a[]
  2. Multi-Dimensional Array: Arrays with two or more dimensions, such as 2D arrays (matrices with rows/columns) or 3D arrays.
  3. Dynamic Array: A resizable array that can grow or shrink in size during runtime, unlike fixed-size static arrays.
